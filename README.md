# Fundamentos de Ingeniería del Software (FIS)

Repositorio oficial del grupo de trabajo para la asignatura **Fundamentos de Ingeniería del Software (FIS)**, parte del **Doble Grado en Ingeniería Informática y Administración y Dirección de Empresas (ADE)** en la universidad.

Este repositorio está diseñado para organizar, almacenar y versionar todas las prácticas y entregas asociadas a la asignatura, facilitando el trabajo colaborativo, el control de versiones y la trazabilidad de los cambios.

Cada carpeta contiene los archivos fuente en **LaTeX** y recursos relacionados con las distintas prácticas desarrolladas durante el curso.

## 🛠️ Tecnologías utilizadas

- **LaTeX** – Para la redacción de documentos técnicos y estructurados.
- **BibTeX** – Gestión de bibliografía.
- **Git** y **GitHub** – Control de versiones y colaboración.

## 📝 Objetivo del repositorio

- Mantener un historial claro y limpio de los avances en las prácticas.
- Fomentar el trabajo en equipo y la colaboración eficiente.
- Aplicar principios básicos de ingeniería del software como control de versiones, documentación y estructuración de proyectos.
